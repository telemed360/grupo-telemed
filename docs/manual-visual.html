09

Tokens CSS

O bloco :root pronto para colar em um site ou sistema.

:root {
  /* Marca */
  --abismo:     #011c26;
  --profundo:   #062836;
  --petroleo:   #26788d;
  --oceano:     #368da3;
  --ceu:        #73c5da;
  --agua:       #83d2e6;
  --nevoa:      #b7e7f3;
  --gelo:       #c2ecf7;

  /* Neutros */
  --ink:        #1e1e1e;
  --ink-soft:   #4a5b61;
  --muted:      #66777d;
  --line:       #e1e9ec;
  --bg-alt:     #f3f8fa;
  --bg:         #ffffff;

  /* Logotipo */
  --wordmark:          #1e1e1e;
  --wordmark-soft:     #717171;
  --wordmark-neg:      #ffffff;
  --wordmark-neg-soft: #e4ebe9;

  /* Forma */
  --radius-lg:  28px;
  --radius:     16px;
  --radius-sm:  10px;
  --shadow-sm:  0 8px 24px -12px rgba(1, 28, 38, .20);
  --shadow:     0 20px 50px -20px rgba(1, 28, 38, .28);

  /* Tipografia */
  --font: "Inter", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}

Os 8 azuis e as cores do texto do logotipo foram medidos nos arquivos da marca. Neutros, gradientes, botões, raios e sombras são uma proposta e podem ser ajustados.

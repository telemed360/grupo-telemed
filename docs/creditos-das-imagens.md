# Créditos das imagens do blog

Todas as fotos do blog vêm do [Pexels](https://www.pexels.com/pt-br/license/). A licença do Pexels permite uso comercial gratuito e não exige crédito.
O site mostra o crédito mesmo assim, em uma legenda pequena abaixo da foto, como boa prática.

Os arquivos ficam em `public/images/blog` e os dados em `src/data/photos.js`. Para trocar uma foto, substitua o arquivo e ajuste o crédito.
Pela licença, não use as fotos de modo que sugira que as pessoas retratadas endossam a marca, nem em contextos que as exponham de forma negativa.
